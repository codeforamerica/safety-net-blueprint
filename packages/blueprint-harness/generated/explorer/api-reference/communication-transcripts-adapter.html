Transcripts Adapter API v0.1.0 Alpha 1 endpoint
Domain: communication-transcripts-adapter · API spec: communication-transcripts-adapter-openapi.yaml
Connect 1

Contracted interface for the state-provided transcripts adapter. The blueprint calls it when transcription software asks to connect, and the adapter answers with where the software connects and a short-lived credential — from the transcription service, or one it signs for a relay the state runs in front of a service a browser can't reach.

The adapter is stateless: one request, one answer. It maps the languages and audio it's given to what its service takes, and holds everything that doesn't change from one call to the next — a region, a custom vocabulary, redaction — as its own configuration. Requests extend AdapterRequest, so the adapter echoes metadata back unchanged.

Base URL: https://adapter.example.com

Connect

Issuing what transcription software connects with.

▶ POST /connect Issue a connection to a transcription service #

Answers with where transcription software connects and a credential that starts one connection, for the service the request names. Every service fits the one answer: a URL that may carry the credential, as Amazon Transcribe's presigned URL does; a token, as ElevenLabs, Deepgram and AssemblyAI issue; or, for a service behind a relay, the relay's URL, its subprotocol and a JWT the adapter signs for it.

Asked again, it issues a fresh credential: that is how software renews one, and how it reconnects.

Request body required
▶ ConnectionRequest
metadata object Opaque correlation context set by the blueprint. Echo back unchanged in the response. The adapter must not inspect or modify this field.
provider enum required The transcription service, an entry of the transcription-services registry.
enumassemblyai aws-transcribe azure-speech deepgram elevenlabs-scribe gladia google-cloud-speech google-gemini-live none openai-realtime soniox speechmatics
model string The service's model, for a service that fixes it when issuing the credential.
▶ languages array[Language] The languages the conversation may be in. The adapter maps them to what its service takes — one, a list, or none to detect — and answers 422 when it can't. Absent, the service detects the language, if it can.
No additional fields
▶ audio AudioFormat required The audio the software will send. Some services fix it into the credential — Amazon Transcribe signs the sample rate into its URL — so the software says it before connecting, in a format its service takes.
encoding enum required How the audio is encoded, by Google Cloud Speech-to-Text's encoding names in the blueprint's casing, which fix the bit depth: linear16 is 16-bit signed little-endian PCM.
enumlinear16 flac mulaw alaw amr amr_wb ogg_opus webm_opus speex_with_header_byte mp3
sampleRateHertz integer required Samples per second, e.g. 16000.
channelCount integer required Channels in the audio. One means the service tells speakers apart by voice; more, that each speaker is on a channel of their own, as a phone call recorded with each side on its own channel is.
▶ protocols array[StreamProtocol] required The protocols the software can connect over. The adapter answers with one of them.
No additional fields
Responses
200 Where and how the software connects.
▶ ConnectionResponse
metadata object required Echoed back unchanged from the request. The blueprint uses this to map the response to its internal records without exposing resource identities to the adapter.
provider enum required The transcription service, as the transcript's profile names it.
enumassemblyai aws-transcribe azure-speech deepgram elevenlabs-scribe gladia google-cloud-speech google-gemini-live none openai-realtime soniox speechmatics
▶ protocol StreamProtocol required How the software connects to the service.
No additional fields
subprotocol string The WebSocket subprotocol the connection speaks, when it is the blueprint's own — `blueprint.transcripts.audio.v1`, which a relay speaks. The software asks for it on connecting. Absent, the connection speaks its service's protocol.
url string (uri) required Where to connect. It may carry the credential itself, as Amazon Transcribe's presigned URL does.
accessToken string The short-lived credential to present on connecting. Absent when the URL carries it.
tokenType string The kind of credential accessToken is, as OAuth names it.
expiresIn integer required Seconds from now until the credential can no longer start a connection. Asking again before then is how a credential is renewed.
connectionParameters object Settings the server chose that the software sends on connecting, in its service's own names — the model and language, say — for a service that takes them then rather than when the credential is issued.
400 The request is malformed or contains invalid parameters.

422 The service can't take what the request asks for — several languages for a service that takes one and can't detect among them, say, or an audio encoding it doesn't accept — named in details.
