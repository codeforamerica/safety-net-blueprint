The transcription software's connection to its transcription service, for one browser tab. Designed to run in the page, beside the software, while the transcript it writes to lives on the server.

Creating a session says which transcript it writes to: an existing one, to carry on after a session failed, or what to start a new one with. A new transcript is started the first time the software asks how to stream. The session's actions are what the client tells it — how do I stream, the connection is open or dropped, a line in progress or finished, pause, resume, stop, close, give up — and each sends an event, which is how the client follows it.

Transcription sessions

The transcription software's connection to its transcription service.

▶ POST /transcription-sessions Start a transcription session createTranscriptionSession #

Start keeping track of the software's connection, for a transcript. Name an existing transcript with transcriptId to carry on after a session failed; otherwise give what a new transcript is started with — profileId, client and startedAt, and model unless the profile's service is none — and it's started the first time the software asks how to stream. The session begins in created.

Body TranscriptionSessionCreate → TranscriptionSession application/json required

transcriptId string · uuid
The transcript the session writes to. Given to carry on a transcript, after a session failed or in a reopened tab; otherwise set when the session starts a new one. To carry on after a reload, the page keeps this id, in sessionStorage for example, and reads the transcript with getTranscript: one still recording or paused can be carried on. A tab opened again has no id kept, and finds the transcript with listTranscripts, by its subject and status: `q=subjectId:{id} status:recording,paused`. A transcript with no subject can't be found that way.
profileId string · uuid
The profile to start a new transcript under.
model string
The transcription service's model, for a new transcript. Required unless the profile's service is `none`.
client string
The transcription software, as `name/version`, for a new transcript.
startedAt string · date-time
When the conversation began, by the client's clock, for a new transcript.
subjectType enum
What kind of thing the transcript records, e.g. `interview` or `call`.
Valuesinterviewchat
subjectId string · uuid
The record of the conversation it transcribes — an interview's id, say. `subjectType` says what kind.
