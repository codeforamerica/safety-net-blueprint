Blueprint mock server, running in this page

No server is involved. The contract set was bundled into a JSON file, and the mock server was bundled into JavaScript — both static files served from wherever this page came from.

What it answers

Create a record

A POST through the same mock.fetch, validated against the contract's request schema, then read back. 

—

Stub an endpoint

Register an HTTP stub and the mock answers from it instead of its own handler, which is how a test forces a response the contract allows but the data does not produce. 

—

Inject an event

The event bus runs in the page too. Publishing an event is how a test drives a state machine without performing the action that would emit it. 

—

Upload a document

A real multipart/form-data request. The bytes are hashed and discarded — the mock stores a description of the file, never its contents, so nothing in a shared fixture can carry real data.

Every route this artifact produced

Built from the contract set at boot — no route is written by hand.
