Not your average Mock Server

This copy is yours

There is no server, so there is nothing shared. Everything here runs in this tab against its own in-memory store — another person opening this page cannot affect your run, and you cannot affect theirs. Two tabs are two independent systems. That is worth noting because it is the usual failure of a hosted mock: one person resetting the data or registering a stub disrupts everyone else using it.

Refreshing starts over from the contracts. Nothing persists, nothing is uploaded, and no request leaves the page — including the document in the upload story, whose bytes are measured and discarded.

The route table, the handlers and the store are the same code the Node server runs. window.mock is on the console.
