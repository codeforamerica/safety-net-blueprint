Events

Centralized event log across all domains.

▶ GET /events List events
Queryable log of all domain events across the blueprint. Supports REST polling as an integration pattern and provides permanent audit history regardless of whether a message broker is in use. Events are returned in ascending time order (oldest first) to support cursor-based polling.

▶ GET /events/stream Stream domain events (SSE)
Real-time stream of domain events delivered as Server-Sent Events (SSE). Connect with `Accept: text/event-stream`. Each event is delivered as a `data:` line containing a JSON-encoded `Event` object. The stream stays open until the client disconnects. A `: heartbeat` comment is sent every 30 seconds to prevent proxy timeouts.
Responses
200 SSE stream of domain events.
string

Registry

Platform-level metadata registries shared across all domains.

▶ GET /registry/policies List policies
Returns all regulatory citations in the platform policy registry, keyed by stable ID. Policies are shared platform-level metadata — not domain- scoped — and serve as the canonical source for annotation displays, compliance tooling, and caseworker UI.

Search

Cross-resource search across all domains.
